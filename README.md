# 💊 Farmacia Vida Natural

**Sistema de gestión para una farmacia desarrollado con Java y MySQL.**

Farmacia Vida Natural es una aplicación de escritorio diseñada para facilitar la administración de las operaciones de una farmacia mediante una interfaz gráfica. Permite gestionar información de productos, categorías, clientes, empleados, proveedores, compras y ventas, centralizando las principales operaciones en un solo sistema.

Este proyecto fue desarrollado como parte de mi formación en el **Curso de Java desde cero a experto**, impartido por **Eutin Academy**.

## 📌 Características principales

- **Gestión de empleados:** administración de usuarios del sistema.
- **Gestión de productos:** registro y administración del inventario.
- **Categorías:** organización de los productos.
- **Clientes:** registro y consulta de información.
- **Proveedores:** administración de datos de proveedores.
- **Compras:** gestión de compras y sus detalles.
- **Ventas:** administración de operaciones de venta.
- **Acceso al sistema:** inicio de sesión para ingresar al panel de administración.

## 🛠️ Tecnologías utilizadas

| Tecnología | Uso |
|---|---|
| Java | Lenguaje de programación |
| Java Swing | Desarrollo de la interfaz gráfica |
| MySQL | Gestión de la base de datos |
| JDBC | Conexión entre Java y MySQL |
| NetBeans IDE | Entorno de desarrollo |
| Git y GitHub | Control de versiones y almacenamiento del código |

## 🗄️ Base de datos

El proyecto utiliza MySQL para almacenar y administrar la información del sistema.

La base de datos se denomina `pharmacy_database` e incluye tablas para gestionar empleados, productos, categorías, clientes, compras, detalles de compra y proveedores, entre otras.

## 📂 Estructura del proyecto

El código fuente está organizado en paquetes para separar las responsabilidades de la aplicación:

- `controllers/`: controladores que gestionan la interacción entre la interfaz y los datos.
- `models/`: clases del modelo y acceso a la base de datos.
- `views/`: interfaces gráficas del sistema.
- `images/`: recursos gráficos utilizados en la aplicación.
- `main/`: punto de entrada de la aplicación.
